# ⌚ PulseOS – Smartwatch Review Sentiment Analyzer

## 📌 Project Overview
PulseOS is a web-based application developed using Streamlit that performs sentiment analysis on smartwatch product reviews. The system analyzes user-entered reviews and classifies them as Positive, Neutral, or Negative using Natural Language Processing techniques.

This project helps users quickly understand public opinion about smartwatch products and also serves as a learning project for NLP and Python-based web applications.

---

## 🚀 Features
- Real-time sentiment analysis of smartwatch reviews  
- Simple and interactive user interface  
- Classifies reviews as Positive, Neutral, or Negative  
- Fast and lightweight application  
- Easy to run on local systems

## 🧠 Working of the Project
1. The user enters a smartwatch review in the input text box.
2. The review text is processed using TextBlob.
3. Sentiment polarity is calculated.
4. Based on polarity, the review is classified as:
   - Positive
   - Neutral
   - Negative
5. The sentiment result is displayed on the screen

---
